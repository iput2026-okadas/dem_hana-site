# はな・はな 公式サイト

宮崎県宮崎市佐土原町のシフォンケーキ店
「はな・はな」のWebサイトです。

## 概要

祖母からの依頼を受けて制作した店舗紹介サイトです。

シフォンケーキを中心とした商品の紹介、
店舗情報、お問い合わせ方法などを掲載しています。

## 主な機能

- レスポンシブ対応
- スムーズスクロール
- スクロールアニメーション
- 商品ギャラリー
- 店舗情報掲載
- 注文案内ページ

## 使用技術

- HTML5
- CSS3
- JavaScript (Intersection Observer)
